# MangueStack · pedidos

Canal público para pedir **correção**, **remoção** ou **inclusão** de uma empresa no [MangueStack](https://manguestack.pages.dev), o hub de tecnologia do Recife.

Este repositório não tem código. Cada pedido vira uma issue, e a resposta fica registrada aqui.

## Como pedir

[Abrir um pedido](https://github.com/Rxmainless/manguestack-pedidos/issues/new?template=pedido.yml)

| Pedido | Prazo |
|---|---|
| Remoção de uma empresa | até 2 dias úteis |
| Correção de dados | até 7 dias, no próximo lote da curadoria |
| Inclusão de uma empresa | entra na fila da curadoria |

## Antes de enviar

- Tudo o que você escrever aqui fica **público**.
- **Não inclua dados pessoais**: CPF, telefone, e-mail pessoal, endereço residencial ou nome de sócios.
- O MangueStack publica dados de empresas, nunca de pessoas. Empresas registradas como MEI ou empresário individual não aparecem no site.

## De onde vêm os dados

Diretório público de embarcadas do Porto Digital, Portal de Dados Abertos do Recife (licença ODbL) e curadoria feita a partir dos sites oficiais das empresas. Cada perfil mostra a fonte e a data de cada informação.

O MangueStack é um projeto independente e não fala em nome do Porto Digital nem da Prefeitura do Recife.
